# LMS - Gestión de Cursos

Este es un proyecto básico para la gestión de cursos en un LMS (Learning Management System).

## Requisitos

- PHP 7.0 o superior
- MySQL
- Servidor web (Apache, Nginx, etc.)

## Instalación

1. Clona el repositorio o descarga los archivos.
2. Importa la base de datos desde `script.sql`.
3. Configura la conexión a la base de datos en `backend/database.php`.
4. Coloca los archivos en tu servidor web.

## Uso

- Accede a `index.html` para iniciar sesión.
- Usa el panel de administración en `admin.html` para gestionar los cursos.
